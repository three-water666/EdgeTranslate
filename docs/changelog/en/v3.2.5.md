# v3.2.5

## Features

-   Added automatic avoidance for the selection button and made it the default mode. The button now checks visible page overlays, chooses among multiple candidate positions, and remains stable during scrolling or delayed popups to reduce overlap and unnecessary repositioning. #33

## Developer Experience

-   Added browser development and production preview commands powered by Playwright-managed Chromium, with persistent development profiles, isolated preview profiles, and automatic project navigation for easier manual extension testing. #32
-   Migrated the extension E2E suite from Selenium/Jest to Playwright, preserving the existing functional scenarios and visual assertions while removing legacy drivers, baselines, scripts, and dependencies. #31
