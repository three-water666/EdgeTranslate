# v3.2.5

## 新功能

-   新增劃詞按鈕自動避讓模式，並設為預設選項。按鈕會偵測頁面上的可見浮層，在多個候選位置中選擇遮擋較少的位置，並在捲動或延遲彈窗出現時保持穩定，減少與網頁控制項重疊或頻繁跳動的情況。#33

## 開發體驗

-   新增由 Playwright 管理 Chromium 的瀏覽器開發與正式版預覽命令，支援持久化開發設定、隔離的預覽設定與自動開啟專案頁面，簡化擴充功能的手動測試流程。#32
-   將擴充功能 E2E 測試從 Selenium/Jest 遷移至 Playwright，保留既有功能情境與視覺斷言，並移除舊有驅動程式、基準檔、腳本與相關相依套件。#31
